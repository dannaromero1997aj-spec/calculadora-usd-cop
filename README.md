# Calculadora USD a COP 💰

Calculadora en Python que convierte salario en USD a pesos colombianos usando la TRM real.

## 🚀 Qué hace
- Trae la TRM en tiempo real con API
- Calcula salario anual, mensual y quincenal en COP
- Calcula cuántos salarios mínimos colombianos son
- Tiene manejo de errores si falla el internet

## 🛠️ Tecnologías
- Python 3
- API: exchangerate-api.com
- Librería requests
